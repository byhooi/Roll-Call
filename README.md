# 班级点名系统

一个基于浏览器的教学辅助工具，提供公平随机点名、学生名单管理与统计分析功能。纯前端实现，数据存储在本地，无需服务器，适合课堂投影或教师自用。

## ✨ 核心特性

### 🎯 公平点名算法
- 优先选择被点名次数最少的学生
- 确保每位学生机会均等，长期使用趋于均匀分布
- 支持空格键快捷点名，提升课堂操作效率

### 📋 学生名单管理
- **Excel 导入**：支持 `.xlsx` 和 `.xls` 格式，自动识别"姓名"和"座位号"列
- **数据验证**：自动检测重复座位号、重复姓名、数据异常等问题
- **手动添加**：实时输入验证，防止错误数据录入
- **安全删除**：操作前显示详细信息确认

### 📊 统计分析
- 实时统计总点名次数、学生总数、平均被点次数
- 详细展示每位学生的点名次数和最后点名时间
- 支持重置统计周期，开启新一轮统计
- 导出 Excel 统计报表

### 💾 数据管理
- **本地存储**：所有数据保存在浏览器 LocalStorage，无需联网
- **自动备份**：每 5 分钟自动备份数据
- **导出备份**：支持导出 Excel 和 JSON 格式
- **数据保护**：导入失败自动回滚，保护原有数据

### 🎨 用户体验
- 响应式设计，支持桌面端和移动端
- 友好的 Toast 通知系统
- 快捷键支持：空格键点名、ESC 键关闭弹窗
- 加载状态和进度提示

### 基本使用流程

#### 1. 导入学生名单

在"学生管理"标签页点击"导入学生名单"，选择 Excel 文件。

**Excel 文件格式要求：**

| 座位号 | 姓名 |
| ------ | ---- |
| 1      | 张三 |
| 2      | 李四 |
| 3      | 王五 |

- 表头必须包含"座位号"（或"座位"）和"姓名"关键字（不区分大小写）
- 座位号必须为正整数
- 系统会自动检测并提示重复或异常数据

#### 2. 开始点名

切换到"点名"标签页，点击"开始点名"按钮或按**空格键**即可随机抽取学生。

被选中的学生会以大字显示，同时显示其被点名次数。

#### 3. 查看统计

在"统计分析"标签页查看详细的点名统计数据，支持导出 Excel 报表。

#### 4. 数据管理

- **重置统计周期**：清零所有点名次数，开始新一轮统计
- **导出数据**：导出学生名单或统计报表
- **清空数据**：删除所有数据（需二次确认）

## 💡 常见问题

### Q: 导入 Excel 时提示"缺少必要的表头"？
A: 确保 Excel 文件第一行包含"座位号"（或"座位"）和"姓名"字段，不区分大小写。

### Q: 如何备份数据？
A: 有两种方式：
1. 系统每 5 分钟自动备份到浏览器本地
2. 手动导出 Excel 报表，可永久保存

### Q: 清空浏览器缓存会丢失数据吗？
A: 是的，清空浏览器数据会删除 LocalStorage。建议定期导出 Excel 备份。

### Q: 可以在多台电脑使用吗？
A: 数据仅存储在本地浏览器，不同设备间不会同步。可通过导入导出 Excel 在多台电脑间迁移数据。

### Q: 点名算法真的公平吗？
A: 算法确保被点名次数少的学生优先被选中，在次数相同时完全随机，长期使用会趋于均匀分布。

### Q: 支持多个班级吗？
A: 当前版本为单班级设计。如需多班级，可以：
1. 使用不同浏览器或浏览器配置文件
2. 定期导出当前班级数据，清空后导入新班级
